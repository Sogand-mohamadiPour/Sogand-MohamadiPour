## 💫 About Me

I'm a **Frontend Developer** focused on building **modern, responsive, scalable, and maintainable web applications**.

My main stack is **React, Next.js, TypeScript, JavaScript, and Tailwind CSS**, with experience in modern frontend architecture, state management, server-state management, API integration, authentication, testing, and production-oriented development.

I enjoy turning complex requirements into **clean, reusable components and intuitive user experiences**, while keeping code maintainable and easy to scale.

### What I work with

* ⚛️ **React & Next.js** — App Router, Server/Client Components, routing, dynamic routes and modern application architecture
* 🟦 **TypeScript** — type-safe application development, interfaces, generics, unions, narrowing and typed APIs
* 📡 **TanStack Query** — server-state management, caching, stale/fresh states, mutations, pagination and dynamic queries
* 🐻 **Zustand** — client-state management, persistent state and application stores
* 🔐 **REST APIs & Authentication** — API integration, authentication flows, OTP verification and protected application flows
* 🧪 **Frontend Testing** — unit, component, integration and E2E testing concepts, user interactions, assertions and TDD
* 🐳 **Docker** — containerizing frontend applications and creating production-oriented Docker workflows
* 🧠 **Algorithms & Problem Solving** — data structures, searching, sorting, recursion, stacks, queues and algorithmic thinking
* 🔧 **Git & GitHub/GitLab** — branching, merging, rebasing, pull requests and collaborative workflows

I also have a background in **English teaching**, which strengthened my communication, problem-solving, presentation, and ability to explain complex concepts clearly.
